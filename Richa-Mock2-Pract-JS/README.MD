# 📦 Inventory Management System

A web-based **Inventory Management System** developed using **HTML, CSS, and JavaScript**. The application helps users efficiently manage inventory items, track stock quantities, calculate stock value, and maintain data using browser LocalStorage.

## 🎯 Project Objective

The main objective of this project is to create a simple and user-friendly system for managing inventory and understanding how JavaScript can be used to build a practical real-world web application.

## ✨ Features

* ➕ Add new inventory items
* ✏️ Edit existing items
* 🗑️ Delete items
* 🔍 Search and filter inventory
* ↕️ Sort items by different criteria
* 💰 Calculate total stock value
* 📊 Display inventory statistics
* 💾 Store data using LocalStorage
* 📥 Export/download inventory data
* ✅ Form validation for accurate data entry

## 🛠️ Technologies Used

* **HTML5** – Structure and layout
* **CSS3** – Styling and responsive design
* **JavaScript** – Logic, CRUD operations and DOM manipulation
* **LocalStorage** – Persistent data storage
* **JSON** – Data handling

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using a browser or Live Server.
4. Start adding and managing inventory items.
